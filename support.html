PadProxy Support

Getting started

  1. Open PadProxy on your iPhone or iPad and tap Start Proxy. Allow local network access when asked.
  2. Join your Mac to the same Wi-Fi network (or to the device's Personal Hotspot).
  3. On the Mac, open System Settings → Wi-Fi → Details… → Proxies and turn on Web proxy (HTTP) and Secure web proxy (HTTPS) using the address and port shown in PadProxy.
  4. Keep PadProxy open with the screen on while you use it. iOS pauses apps that leave the screen.

Troubleshooting

  • The Mac can't connect: check that both devices are on the same network, that Local Network access is on for PadProxy (Settings → Privacy & Security → Local Network), and that the Wi-Fi doesn't isolate clients (common on guest networks). Personal Hotspot is a reliable alternative.
  • Terminal tools ignore the proxy: run export https_proxy=http://<address>:<port> http_proxy=$https_proxy.
  • "Address already in use": choose another port or wait a few seconds after stopping.
  • If you share a work VPN connection this way, make sure your organization's policy allows it.
